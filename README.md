# 시간 맞춰 가장 저렴하게

목적지와 도착 제한 시각을 입력하면, 그 안에 도착할 것으로 예상되는 대중교통 경로를 비용순으로 비교하고 출발 시각을 알려주는 해커톤 프로젝트입니다.

현재는 두 명의 공동 작업 공간과 업무 목표를 준비한 단계입니다. 실제 서비스와 알림 코드는 아직 구현하지 않았습니다.

## 역할과 목표

| 담당 | 목표 | 완료 기준 |
| --- | --- | --- |
| 저장소 소유자 `Chinakimchi` | 네이버 지도 화면 흐름 분석, 입력·결과 화면 설계, 통합과 발표 | `plan.md` 원본 해부 기록, 화면에서 목적지·제한 시각과 경로 결과 시연 |
| 공동 작업자 `cloniante-prog` | 공식 공개 경로 API 검증, 비용·시간 비교 규칙, 자동 알림 | 실제 API 응답의 시간·요금·단계 확인, 자동 실행과 중복 없는 텔레그램 알림 시연 |
| Codex | 공통 설계와 구현, 테스트, 두 작업의 통합 지원 | 데이터 형식 합의, 코드 검증, 남은 준비 사항 안내 |

두 사람이 함께 결정할 사항은 입력 범위, 경로 후보의 범위, 도착 여유시간, 알림 조건입니다. 결론을 `plan.md`에 남깁니다.

## 개발 순서

1. 네이버 지도 사용 흐름을 읽기 전용으로 분석하고 `plan.md`의 원본 해부를 채웁니다.
2. 공개 API의 실제 응답에서 경로별 소요시간·요금·이동 단계를 확인합니다.
3. 목적지·도착 제한 시각을 입력하는 화면을 만듭니다.
4. 남은 시간 내 도착 가능한 경로를 골라 예상 비용순으로 정렬합니다.
5. GitHub Actions와 텔레그램 알림을 연결하고 중복 발송을 검사합니다.
6. 배포, 출처·키 노출 검사, 시연 자료를 마무리합니다.

초기 MVP는 대중교통 경로와 그 안의 도보·버스·지하철 구간을 대상으로 합니다. 예상 시간과 요금은 실제 도착·지출을 보장하지 않으며, 데이터 제공 범위는 API 실응답 확인 후 확정합니다.

## 협업 방법

- 각자 작업용 브랜치를 만들고, 변경 사항은 Pull Request로 합칩니다.
- 비밀 키와 토큰은 저장소 파일에 적지 않고 GitHub Actions Secrets나 로컬 환경변수에 둡니다.
- 원본 서비스의 앱 파일 또는 비공개 API를 사용하지 않습니다.
- 분석 캡처와 참고 자료를 올리기 전 개인정보나 키가 없는지 확인합니다.

## 준비가 필요한 계정

- 카카오디벨로퍼스 앱과 REST API 키: 공식 대중교통 경로 조회용
- 텔레그램 봇 토큰과 알림받을 채팅 ID: 출발 알림용

키가 준비되면 값은 채팅으로 보내지 말고 저장소의 Secrets에 직접 등록합니다. 등록 방법은 연동 작업을 시작할 때 안내합니다.

## 데이터 후보
